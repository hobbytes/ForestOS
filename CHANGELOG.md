# История изменений

## 2.0 — Revival (Wet Stone)

Первая публичная версия после возрождения проекта.

**Система**
* запуск оригинального Forest OS на PHP 8.3 в Docker (Apache + MariaDB), установка
  одной командой и bootstrap первичной настройки;
* чистая структура репозитория: `Dockerfile`, `docker-compose.yml`, `bin/`,
  `sql/`, `docs/`, `.env.example`, без секретов и пользовательских данных.

**Рабочий стол**
* окна с перетаскиванием, изменением размера, сворачиванием «в плашку» и z-order;
* сетка ярлыков: не накладываются, но двигаются свободно, подсказка-сетка при переносе;
* создание папок и файлов прямо на столе, удаление ярлыков;
* динамическое обновление дока и рабочего стола без перезагрузки;
* контекстные меню везде, меню текста (копировать/вырезать/вставить).

**Приложения**
* четыре стандартных: Explorer, Settings, Apps House, Update (защищены от удаления);
* остальные (Rich Text Editor, Image Viewer, Audio Player, Converter, Demo,
  примеры) публикуются в Apps House и ставятся из магазина;
* магазин: каталог, установленные, обновления, репозитории, публикация своих приложений.

**Node-режим** (`Ctrl+Shift+N`)
* входы и выходы приложений, якоря на окнах и элементах, провода между ними;
* кнопки как действия и события (`data-fo-action`, `data-fo-event`);
* режимы «Авто» и «По запуску», сохранение пространств.

**Оформление**
* темы, акцентный цвет, тёмная тема, SVG-иконки в настройках;
* конвертер старых приложений на переменные темы;
* файлы на рабочем столе — белая страница с иконкой приложения.

**Мобильный режим (≤ 760 px)**
* полноэкранные приложения, нижняя панель, док-панель;
* список запущенных с закрытием одного или всех, свайп от края, долгое нажатие.

**Обновления**
* `bin/release.php` собирает пакет из GitHub и публикует `releases/update.json` + архив;
* приложение Update показывает версию, описание и ставит обновление в один клик
  (только суперпользователь), сохраняя `.env`, `system/users`, `data` и настройки;
* альтернатива — GitHub Releases (workflow запускается вручную).
