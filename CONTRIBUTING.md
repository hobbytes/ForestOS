# Как участвовать в разработке

Спасибо, что хотите помочь! Проект маленький и дружелюбный — здесь нет сборки,
линтеров и обязательных ревью-ботов.

## Ветки

* `main` — рабочая стабильная версия (то, что разворачивают).
* `feature/<короткое-имя>` — новая функция.
* `fix/<короткое-имя>` — исправление.

Пожалуйста, не коммитьте прямо в `main`: создайте ветку и пришлите Pull Request.

## Что можно присылать

* новые приложения в `system/apps/<Имя>/` (см. `system/apps/PickerTest` — минимальный пример);
* улучшения оболочки (`system/core/library/js/`), стилей (`system/core/design/`);
* новые темы в `system/core/design/themes/*.fth`;
* переводы (`system/apps/*/lang/`, `system/*/lang/`);
* исправления ошибок и документации.

## Правила для приложений

1. Приложение — папка `system/apps/Имя/` с `main.php` (и `assets/`, `lang/`, `app.png`).
2. Используйте `AppContainer` (`system/core/library/Mercury/AppContainer.php`):
   `StartContainer()` … `EndContainer()`.
3. Не задавайте цвета «в лоб» — берите переменные темы:
   `var(--fo-win-body)`, `var(--fo-text)`, `var(--fo-accent)`. Старые приложения
   можно прогнать через приложение **Converter**.
4. Файл приложению передаётся параметром `defaultloader` (путь от корня сайта) —
   это стандартный «вход», его использует Node-режим.
5. Входы/выходы для Node-режима: `data-fo-in`, `data-fo-out`, `data-fo-action`,
   `data-fo-event` на элементах.

## Стиль кода

* PHP: 4 пробела, `<?php` или короткий `<?` как в соседних файлах, без внешних зависимостей.
* JS: обычный ES5-совместимый код, IIFE, без сборщиков; jQuery уже подключён.
* CSS: переменные темы, никаких внешних шрифтов и CDN, кроме существующих.
* Не добавляйте `alert()` — есть `FO_TOAST('текст')` и уведомления системы.

## Проверка перед PR

* страница открывается без ошибок в консоли;
* вход/выход, окна, док работают;
* на узком экране (≤ 760 px) интерфейс не разваливается;
* `php -l` на изменённых PHP-файлах без ошибок;
* в диффе нет `.env`, паролей, личных файлов и больших бинарников.

## Секреты

Пароли БД и администратора — только в `.env`. В репозитории есть только
`.env.example` с заглушками. Если случайно закоммитили секрет — сразу смените его
и напишите в issue/PR, мы поможем вычистить историю.
